# Dapur Mie Rawit 🌶️🍜

Game masak berbasis browser bertema warung mie pedas. Layani pelanggan yang memesan mie pedas, dimsum, dan es secepat mungkin, kumpulkan uang, lalu kembangkan warungmu.

## Cara main

1. Pelanggan datang dan memesan. Gelembung di atas kepala berisi pesanannya, bar di bawah nama menunjukkan kesabarannya.
2. Tekan **Rebus Mie**. Setelah matang, pilih level pedas (Lv 0–4) sesuai pesanan. Jangan dibiarkan terlalu lama, mie bisa lembek.
3. Siapkan dimsum di wajan dan minuman di dispenser es. Hasilnya otomatis pindah ke nampan saji.
4. Ketuk pelanggan untuk mengantar pesanan. Makin cepat, makin besar tip dan poinnya.
5. Layani semua pelanggan untuk naik level. Kalau 3 pelanggan kabur, level gagal.

## Fitur

- Level bertingkat dengan menu baru, pedas lebih tinggi, dan pelanggan yang makin tidak sabar.
- Toko fasilitas: kompor, wajan, dispenser es, antrean, panci presto, kipas angin & AC.
- Karyawan otomatis: Koki Mie, Juru Dimsum, Peracik Es, dan Pelayan (digaji per level).
- **Popularitas**: setiap fasilitas dan karyawan membuat warung makin terkenal, jadi pelanggan makin ramai, makin menuntut, dan muncul pelanggan VIP.
- Progres tersimpan otomatis di browser (localStorage).

## Menjalankan

Tidak perlu instalasi. Buka `index.html` di browser, atau aktifkan **GitHub Pages**:
**Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.**
Game akan tersedia di `https://<username>.github.io/<nama-repo>/`.

## Teknologi

HTML, CSS, dan JavaScript murni dalam satu file. Grafis digambar dengan SVG, suara dengan Web Audio API.
